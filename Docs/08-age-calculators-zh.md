# 页面设计：狗狗和猫咪年龄计算器

**URLs**:  
- `https://petsmetrics.com/dog/age-calculator/`  
- `https://petsmetrics.com/cat/age-calculator/`  
**模板**: A — 工具页面（带侧边栏的两列布局）  
**优先级**: P0 · 上线日  
**社交分享价值**: 非常高（"我的狗狗在人类年龄是 33 岁！"）

---

## 1. 页面目标

高流量、社交可分享的工具。用户在社交媒体上分享结果 → 有机反向链接 + 品牌知名度。

狗狗计算器必须实现**修正的基于体型的公式**（不是过于简化的 "7× 规则"），引用 2020 年 UCSD 甲基化研究来建立科学可信度。

猫咪计算器使用官方的 **AAHA/AAFP 2021 猫生命阶段指南**。

### [6] 背后的科学

```
  为什么我们不使用 "7× 规则"        （H3，可展开）
  ─────────────────────────────────────────────────────

  流行的 "乘以 7" 公式没有科学依据。
  狗狗在头 2 年快速成熟（达到性成熟和完整体型），之后衰老得更慢。

  我们的计算器使用来自以下机构的体型调整生命阶段指南：
  · 美国动物医院协会（AAHA）
  · 2020 年 UCSD 表观遗传学甲基化研究（拉布拉多参考）
  
  较大品种衰老得更快，因为它们的代谢率更高和细胞分裂更快 — 不是因为体型本身。

  [阅读 UCSD 研究 →]  （链接到 PubMed）
  [AAHA 生命阶段指南 →]
```

此内容服务于双重目的：SEO（独特、可引用的内容）+ 可信度建立。

#### 动态 OG 分享卡片（每个结果自动生成）

每个结果页面生成一个独特的 Open Graph 图像，以便在 Twitter/Facebook/iMessage 上分享时，预览卡片显示宠物的结果 — 而不是通用的主页图像。这是病毒式分享的主要驱动力。

**技术实现**：`@vercel/og` 或 `satori` 库。由 URL 参数触发（例如 `/dog/age-calculator/?years=3&size=large&result=28&name=Buddy`）。在构建边缘服务器端生成 PNG，无需后端。

**分享卡片视觉规范**（1200×630px）：
