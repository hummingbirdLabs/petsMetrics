# 页面设计：猫咪工具枢纽

**URL**: `https://petsmetrics.com/cat/`  
**模板**: B — 枢纽/落地页（全宽区块）  
**优先级**: P0 · 上线日  
**主题色**: 优雅紫罗兰色（`--cat-primary` #7C3AED）

---

## 1. 页面目标

所有猫咪相关工具的落地页。用作：
- "猫咪健康工具"、"猫咪计算器"的 SEO 入口点
- 养猫用户的导航枢纽
- 差异化语调：比狗狗枢纽更冷静、更精致

---

## 5. 视觉设计 — 紫罗兰色主题细节

### 颜色应用

| 元素 | 规范 |
|---|---|
| Hero 渐变 | `#4C1D95 → #7C3AED → #A78BFA` |
| 工具卡片图标 | `--cat-primary` #7C3AED |
| 卡片悬停边框 | `--cat-accent` #A78BFA |
| 档案栏背景 | `--cat-primary-light` #EDE9FE |
| 特色卡片左边框 | `--cat-primary` 4px |
| 标签徽章 | `--cat-primary-light` 背景，`--cat-primary` 文本 |
| 页面表面色调 | `--cat-surface` #F5F3FF |

### 猫咪页面的排版改进

猫咪页面使用稍微更宽松的字间距（`0.01em`）和更柔和的视觉重量，以匹配更精致的品牌语调。相同的字体栈，相同的大小 — 在应用中有细微的行为差异。

---

## 6. 移动端布局（≤ 768px）

与狗狗枢纽相同的响应式策略：
- Hero: 28px H1，仅面包屑，无搜索
- 档案栏: 压缩并带有自动填充指示器
- 特色卡片: 全宽，紫罗兰色强调
- 工具网格: 1 列
- FAQ: 手风琴保持功能，无需 JS
