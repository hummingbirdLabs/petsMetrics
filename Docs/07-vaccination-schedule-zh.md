# 页面设计：疫苗和驱虫计划生成器

**URLs**:  
- `https://petsmetrics.com/dog/vaccination-schedule/`  
- `https://petsmetrics.com/cat/vaccination-schedule/`  
**模板**: A — 工具页面（带侧边栏的两列布局）  
**优先级**: P0 · 上线日  
**适用对象**: 狗狗和猫咪（单独页面，相同模板）

---

## 1. 页面目标

网站上**留存率最高的工具**。用户反复返回查看即将到来的疫苗日期。这创造了一个自然的电子邮件收集机会（疫苗提醒 = 所有工具中最高的选择加入率）。

**主要价值**: 再也不会错过疫苗。可打印的日期时间表，个性化到宠物的确切年龄和地区。  
**变现方式**: 保险联盟横幅 — "兽医就诊保障"是此页面最强的转化钩子。

**状态图标图例**:
- ✅ 已完成: `--status-safe` 绿色，删除线文本
- ⚠️ 60 天内到期: `--status-caution` 琥珀色，粗体日期
- 🚨 过期: `--status-toxic` 红色，粗体 "过期" 标签
- ⏳ 即将到来: `--gray-500`，正常字重

**表格行设计**:
- 斑马纹: `--white` / `--gray-50`
- 核心疫苗: 正常行
- 区域分隔线: `--gray-200` 边框，带有区域标签
- 非核心疫苗行: 斜体样式，信息图标带有提示框

#### 电子邮件提醒 CTA（内联，全宽 — 直接在结果下方）

> **位置理由**: 这是网站转化最高的电子邮件选择加入时刻。用户刚刚看到了他们宠物的完整疫苗时间线，并且确切知道下一次注射何时到期 — 提醒的价值立即显而易见。将此放在侧边栏（位置 [C]）会浪费转化窗口；它必须内联、全宽显示，紧跟在计划表格之后。

```
┌─────────────────────────────────────────────────────────────────┐
│  📧  再也不会错过疫苗 — 为 Buddy 获取提醒                        │
│  ─────────────────────────────────────────────────────────────  │
│  每次疫苗到期前 1 周我们会给您发送电子邮件。                        │
│  免费。无垃圾邮件。随时取消订阅。                                  │
│                                                                 │
│  ┌──────────────────────────────────────┐  [设置提醒 →]          │
│  │  your@email.com                      │                        │
│  └──────────────────────────────────────┘                        │
│                                                                 │
│  ✓ 符合 GDPR  ·  ✓ 仅疫苗提醒  ·  ✓ 免费                      │
└─────────────────────────────────────────────────────────────────┘
```

- 背景: `--status-info-bg` `#DBEAFE`，左边框: 4px `--status-info` `#3B82F6`
- 全宽块，不是侧边栏 — 无论滚动深度如何都能保证可见性
- 如果用户已经提供了电子邮件（例如来自档案备份步骤），则预填充字段
- GDPR: 欧盟用户的显式复选框: "我同意接收 Buddy 的疫苗提醒电子邮件"
- 此块替换了侧边栏位置 [C] 中的电子邮件 CTA（见下面的侧边栏规范）

## 5. 猫咪疫苗接种计划差异

**猫咪核心疫苗（WSAVA / AAHA-AAFP 2021）**:

| 年龄 | 核心疫苗 |
|---|---|
| 6–8 周 | FVRCP（第 1 剂） |
| 10–12 周 | FVRCP（第 2 剂） |
| 14–16 周 | FVRCP（第 3 剂） + 狂犬病 |
| 1 年 | FVRCP 加强 + 狂犬病 |
| 每 3 年 | FVRCP + 狂犬病（3 年方案） |

**猫咪非核心疫苗**:
- FeLV（猫白血病）: 仅限户外猫
- FIV: 高风险户外猫
- 猫博德特氏菌: 多猫家庭或收容所

**猫咪页面的主要 UI 差异**:
- 全程使用紫罗兰主题
- 生活方式复选框: "仅室内 / 室内-室外 / 仅室外"（比狗狗更适合猫咪）
