# 页面设计：怀孕和预产期计算器

**URLs**:  
- `https://petsmetrics.com/dog/gestation-calculator/`  
- `https://petsmetrics.com/cat/gestation-calculator/`  
**模板**: A — 工具页面（带侧边栏的两列布局）  
**优先级**: P0 · 上线日  
**适用对象**: 狗狗（平均 63 天）和猫咪（平均 65 天）— 相同页面模板，不同数据

---

## 1. 页面目标

为繁殖者和新宠物主人服务，他们想要：
1. 从交配日期计算预产期
2. 了解怀孕期间的关键兽医里程碑
3. 准备分娩/产仔

**主要变现方式**: 保险联盟横幅（新窝 = 保险销售高峰）。  
**SEO 目标**: "狗狗怀孕计算器"、"狗狗预产期计算器"、"狗狗怀孕多久"、"猫咪怀孕计算器"

#### 结果 B — 里程碑时间线

一个可视化的水平（桌面）或垂直（移动）时间线：

```
  ──────────────────────────────────────────────────────────────
  
  第 0 天        第 28 天        第 45 天        第 55 天        第 63 天
  6月5日         7月3日         7月20日         7月30日         8月7日
    │              │              │              │              │
    ●──────────────●──────────────●──────────────●──────────────●
    │              │              │              │              │
  交配发生      建议超声检查     X光可见幼犬     准备分娩箱     预产期
                （确认怀孕）
```

**时间线组件**:
- 每个里程碑: 圆点（如果已过去，填充青色；如果未来，灰色；如果"现在"，脉动琥珀色）
- 悬停/点击时的里程碑卡片:
  ```
  ┌─────────────────────────────────────────────────┐
  │  第 28 天 · 2026年7月3日                       │
  │  建议超声检查                                   │
  │  您的兽医可以在第 25–35 天通过超声检查确认怀孕并  │
  │  估算窝数。                                       │
  │  [为什么这很重要 →]  （可展开）                  │
  └─────────────────────────────────────────────────┘
  ```
- 移动端: 垂直时间线（从上到下），卡片始终可见（无悬停）

**狗狗里程碑**:

| 天 | 日期 | 里程碑 | 操作 |
|---|---|---|---|
| 0 | 交配 | 可能受孕 | 监测怀孕迹象 |
| 21 | 第 21 天 | 可能出现孕吐 | 正常，短暂 |
| 25–35 | 第 25–35 天 | 超声检查窗口 | 预约兽医 |
| 42–45 | 第 42–45 天 | 骨骼 X 光 | 从第 45 天开始数胎儿骨骼 |
| 55 | 第 55 天 | 准备分娩箱 | 安静、温暖、易接近的位置 |
| 58 | 第 58 天 | 可能提前分娩 | 开始体温监测 |
| 63 | 第 63 天 | 最可能的预产期 | 预期分娩 |
| 68 | 第 68 天 | 最晚边界 | 如果未分娩联系兽医 |

**猫咪里程碑**:

#### 结果 C — 准备清单

时间线下方的可展开手风琴：

```
  ▼  分娩准备清单
  ─────────────────────────────────────────────────────────────

  □  预约超声检查（第 25–35 天）
  □  预约 X 光检查（从第 45 天开始）
  □  在第 55 天前设置好分娩箱
     → 推荐箱大小: [根据品种大小自动计算]
  □  收集分娩用品
     → 温度计、干净毛巾、加热垫、秤
  □  确定 24 小时急诊兽医诊所
  □  从第 60 天开始直肠体温监测
     → 体温降至 99°F 以下表示将在 12–24 小时内分娩
```

清单项目是交互式的（复选框），状态保存到 localStorage。
