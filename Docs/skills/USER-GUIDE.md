# Skills 用户指导手册

> 本文档指导你如何使用 `.trae/skills/` 目录中的 AI Skills。

---

## 1. 什么是 Skill？

Skill 是预定义的 AI 专家角色和流程。当你提出特定需求时，AI 会自动匹配最合适的 Skill，以专业的方式完成任务。

每个 Skill 包含：
- **角色**：AI 扮演的专家身份
- **触发条件**：哪些关键词或需求会激活此 Skill
- **执行协议**：分步骤的操作流程
- **输出格式**：标准化的交付物

---

## 2. Skill 清单与使用场景

### 2.1 i18n Auditor — 多语种审计

**何时使用**：
- "检查多语言覆盖"
- "添加法语支持"
- "有没有硬编码字符串"
- "翻译不完整"

**你会得到什么**：
- 当前语言覆盖情况
- 缺失的翻译键值列表
- 硬编码字符串位置及修复建议
- 可直接执行的新增语言文件

**示例指令**：
```
检查一下项目中哪些页面还没有支持中文，直接修复简单的问题，复杂的列出来给我。
```

---

### 2.2 Webmap Generator — 站点地图生成

**何时使用**：
- "统计有多少页面"
- "更新 webmap.md"
- "列出所有工具页和对应的代码文件"

**你会得到什么**：
- `Docs/webmap.md` 自动更新，包含：
  - 页面总数统计
  - 语言覆盖矩阵
  - 完整路由清单及对应文件路径
  - sitemap 一致性检查结果

**示例指令**：
```
统计当前页面情况，更新到 webmap.md 中，包含每个页面对应的代码文件。
```

---

### 2.3 GEO Auditor — AI 搜索引擎优化

**何时使用**：
- "检查 GEO 优化情况"
- "AI 搜索引用率"
- "Knowledge Card 合规吗"
- "FAQ Schema 完整吗"

**你会得到什么**：
- 逐页面的 GEO 合规检查
- JSON-LD 结构化数据完整性
- robots.ts AI 爬虫策略评估
- P0/P1/P2 分级修复建议

**示例指令**：
```
分析项目的 GEO 情况，无风险就修复，有决策点的按优先级输出给我。
```

---

### 2.4 SEO Auditor — 传统 SEO 审计

**何时使用**：
- "SEO 审计"
- "metadata 完整吗"
- "sitemap 有没有问题"
- "Core Web Vitals 合规"

**你会得到什么**：
- 全站 metadata 检查（title/description/canonical）
- JSON-LD Schema.org 验证
- 内部链接矩阵评估
- SpamBrain 风险标记

**示例指令**：
```
阅读项目代码分析 SEO 情况，如果无风险就直接修复了；如果工作量较大，按优先级排序输出给我。
```

---

### 2.5 Feature Builder — 新增功能

**何时使用**：
- "我想加一个功能"
- "新增 XX 计算器"
- "做一个 XX 页面"
- 提供一句话需求

**你会得到什么**：
- `Docs/prd/` 目录下的需求文档（PRD）
- `Docs/prd/` 目录下的技术方案
- 完整的代码实现（计算函数 + 组件 + 页面 + i18n）
- 单元测试

**示例指令**：
```
我想新增一个"狗狗怀孕计算器"，输入交配日期输出预产期。
```

**执行流程**：
1. AI 向你澄清 1-3 个关键问题
2. 生成 PRD 文档
3. 生成技术方案
4. 按 TDD 顺序编码实现
5. 自动运行质量门禁

---

### 2.6 404 Detector — 死链与路由健康检测

**何时使用**：
- "有没有 404 问题"
- "检查死链"
- "路由健康检查"
- "not-found 页面完整吗"

**你会得到什么**：
- 内部死链清单及文件定位
- `generateStaticParams()` 缺失检查
- not-found.tsx 覆盖状态
- 外部链接风险标记

**示例指令**：
```
分析项目中是否存在 404 问题，如果无风险就直接修复；如果工作量较大，按优先级排序输出给我。
```

---

### 2.7 Color Auditor — 颜色对比度审计

**何时使用**：
- "检查颜色对比度"
- "WCAG 合规吗"
- "深色模式颜色有问题"
- "设计一个新的配色方案"

**你会得到什么**：
- 全站颜色 token 对比度计算报告
- 不合规配对及修复建议
- 硬编码颜色清理清单
- 新增颜色的推荐值（含浅色/深色双版本）

**示例指令**：
```
分析所有页面的颜色对比度是否符合 WCAG AA 标准，修复不达标的。
```

## 3. 使用模式

### 3.1 直接提问（推荐）

直接用自然语言描述你的需求，AI 会自动匹配 Skill：

```
"检查 SEO 并修复简单问题"
"添加德语支持"
"统计页面更新 webmap"
```

### 3.2 显式调用

如果你想指定使用某个 Skill，可以明确提及：

```
"用 i18n Auditor 检查多语言覆盖"
"执行 GEO 审计"
"走 Feature Builder 流程，需求是：狗狗咳嗽评估器"
```

### 3.3 批量审计

想一次性检查多项：

```
"P0 全面审计：检查 SEO + GEO + 404 + 颜色对比度，
无风险直接修复，需要决策的按优先级列出来。"
```

## 4. 输出约定

所有 Skill 遵循相同的输出约定：

| 符号 | 含义 |
|------|------|
| ✅ | 已通过 / 已完成 |
| ⚠️ | 需要注意 / 警告 |
| 🔴 P0 | 阻塞性问题，必须修复 |
| 🟡 P1 | 重要问题，本版本修复 |
| 🟢 P2/P3 | 优化建议，后续迭代 |

**可自动修复的条件**：
- 问题明确且修复方案唯一
- 不涉及新增业务逻辑
- 不涉及外部内容（需人工撰写）
- 不涉及业务决策

**需要你确认的情况**：
- 工作量超过 20 个文件变更
- 涉及新增语言（需外部翻译审核）
- 涉及外部链接有效性（需人工验证）
- 涉及内容撰写（毒性描述、SEO 正文等）

## 5. Skill 边界说明

```
┌─────────────────────────────────────────────────────┐
│                   Feature Builder                    │
│    (新增功能入口，内部协调其他 Skill)                  │
├─────────────┬─────────────┬─────────────────────────┤
│  i18n       │  Webmap     │  Color                  │
│  Auditor    │  Generator  │  Auditor                │
│  (翻译)     │  (文档)     │  (视觉)                 │
├─────────────┴─────────────┴─────────────────────────┤
│     SEO Auditor          │      GEO Auditor         │
│     (传统搜索)            │      (AI 搜索)           │
├──────────────────────────┴─────────────────────────┤
│                  404 Detector                       │
│                  (路由健康)                          │
└─────────────────────────────────────────────────────┘
```

**边界规则**：
- SEO 负责传统搜索（sitemap、Core Web Vitals、外链）
- GEO 负责 AI 搜索（Knowledge Card、citation[]、AI 爬虫）
- 404 负责路由完整性（不与其他 SEO/GEO 工作重复）
- Feature Builder 在编码完成后，自动触发 i18n / SEO / GEO / Color 的自检

## 7. 常见问题

**Q: Skill 执行失败了怎么办？**
A: Skill 设计为防御性流程。如果某个步骤无法完成，AI 会明确标注原因并输出已完成的部分，不会静默失败。

**Q: 能否修改 Skill 的行为？**
A: 可以。直接编辑 `.trae/skills/SKILL-xxx.md` 文件中的"执行协议"部分。建议修改前备份。

**Q: 新增 Skill 需要什么步骤？**
A: 使用 `skill-creator` Skill 创建新的 SKILL-xxx.md 文件，包含：角色定义、触发条件、执行协议、约束条件。

**Q: 多个 Skill 会冲突吗？**
A: 不会。每个 Skill 有独立的职责范围。显式调用时按指定 Skill执行；自然语言提问时选择最匹配的一个。批量审计时按依赖顺序串行执行。
