# 页面设计：首页

**URL**: `https://petsmetrics.com/`  
**模板**: C — 首页（全出血 Hero + 分区块内容）  
**优先级**: P0 · 上线日

---

## 1. 页面目标

在 **10 秒内** 将首次访客转化为工具用户。首页必须传达：
1. 这个网站是做什么的（一句话）
2. 它的不同之处（宠物档案数据联动）
3. 下一步该做什么（开始使用工具或创建宠物档案）

#### Hero 文案

**H1 标题**（56px / 800 字重 / 白色）:
> 一个档案。所有答案。

**副标题**（20px / 400 字重 / `rgba(255,255,255,0.8)`）:
> 只需创建一次宠物档案 — 然后每个计算器都会自动填充。  
> 无需登录。无需 AI。只有科学。

**CTA 按钮**（2 个一排）:
- 主要: `[🐕 狗狗工具]` — 琥珀色背景 `--dog-primary`，白色文本，52px 高度
- 次要: `[🐱 猫咪工具]` — 紫罗兰色背景 `--cat-primary`，白色文本，52px 高度

**信任信号行**（14px，`rgba(255,255,255,0.6)`）:
> 200+ 种食物检测 · 14 个工具 · 400+ 品种 · 基于 AAHA、WSAVA 和 AAFCO 标准

> ⚠️ **设计说明**: 上线时 **不要** 使用编造的用户数（例如"50,000+ 宠物主人"）。这是一个没有用户基础的新网站 — 虚假的社会证明会破坏持怀疑态度的西方受众的信任，并在 FTC/ASA 指南下带来法律风险。在有真正的用户数据之前，使用可验证的数据指标（数据库大小、品种覆盖、公式来源）。一旦验证用户超过 5,000，可以添加真实计数。

#### 右列 — 动画宠物档案卡片

这是 hero 的视觉"顿悟时刻" — 一个动画的宠物档案卡片 mockup，每隔 3 秒平滑淡入淡出切换不同的工具输出（卡路里 → 年龄 → 疫苗接种 → 怀孕）。

**卡片规格**:
- 背景: `rgba(255,255,255,0.06)` glass morphism
- 边框: `1px rgba(255,255,255,0.12)`
- Backdrop-filter: `blur(20px)`
- Border-radius: 20px
- 阴影: `0 24px 48px rgba(0,0,0,0.4)`
- 宽度: 最大 360px

**移动端行为**: 卡片堆叠在标题下方。宽度缩小到 280px。

## 7. 动画时间线（页面加载时）

| 元素 | 延迟 | 动画 |
|---|---|---|
| 导航 | 0ms | 淡入 |
| Hero 标题 | 100ms | 上移 20px 淡入 |
| Hero 子文本 | 250ms | 上移 20px 淡入 |
| CTA 按钮 | 400ms | 上移 20px 淡入 |

| 社会证明 | 600ms | 淡入 |
