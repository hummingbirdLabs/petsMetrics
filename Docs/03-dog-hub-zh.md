# 页面设计：狗狗工具枢纽

**URL**: `https://petsmetrics.com/dog/`  
**模板**: B — 枢纽/落地页（全宽区块）  
**优先级**: P0 · 上线日  
**主题色**: 温暖琥珀色（`--dog-primary` #D97706）

---

## 1. 页面目标

所有狗狗相关工具的落地页。用作：
- "狗狗健康工具"、"狗狗计算器"的 SEO 入口点
- 用户浏览狗狗工具的导航枢纽
- 回访用户的快速访问网格

---

## 2. SEO 元数据

```
Title:    免费狗狗健康计算器 — 卡路里、年龄、疫苗及更多 | petsMetrics
Desc:     基于科学的狗狗计算器：卡路里需求、人类年龄换算、幼犬成长、疫苗接种计划和怀孕预产期。免费，无需登录。AAHA 标准。
Canonical: https://petsmetrics.com/dog/
Schema:   CollectionPage + BreadcrumbList
H1:       狗狗健康计算器和工具
```

**目标关键词**: "狗狗卡路里计算器"、"狗狗人类年龄换算"、"幼犬成长图表"、"狗狗疫苗接种计划"、"狗狗怀孕计算器"

### 区块 6 — 品种特定 SEO 内容（低竞争长尾）

**背景**: `--gray-50`  
**内边距**: 垂直 64px  
**目的**: 捕获大型网站（AKC、PetMD）在页面级别没有优化的品种特定搜索查询。这些关键词的 DA40 或更低竞争 — 新网站可以在 3–6 个月内排在第 1 页。

**目标查询模式**:
- "德国牧羊犬卡路里计算器"
- "金毛寻回犬人类年龄"
- "法国斗牛犬健康体重"
- "拉布拉多幼犬成长图表"

```
  按品种分类的工具                           （H2）
  ───────────────────────────────────────────
```
