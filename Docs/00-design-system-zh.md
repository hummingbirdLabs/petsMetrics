# PetsMetrics — 设计系统与视觉语言

---

## 1. 品牌识别

### 1.1 标志概念

```
🐾 petsMetrics
```

- **标志图形**: 简约的爪印，内部嵌入微妙的图表/统计图元素
- **文字标志**: `pets` 使用常规字重 + `Metrics` 使用半粗体
- **安全空间**: 四周保持 2 倍标志高度的空白
- **最小尺寸**: 120px 宽（数字），30mm（印刷）

### 1.2 品牌语调

| 属性 | 描述 |
|---|---|
| **权威** | 引用 AAHA、WSAVA、AAFCO — 每个数字都有来源 |
| **温暖** | 像一位博学的朋友，而不是临床报告 |
| **精准** | 没有模糊的范围，清晰的公式，透明的方法论 |
| **安全** | 医疗决策始终优先咨询兽医 |

### 2.5 深色模式 Token 覆盖

> **为什么需要**: 截至 2025 年，55–70% 的 iPhone/Mac 用户启用了系统深色模式（Apple 内部数据）。忽略 `prefers-color-scheme: dark` 的网站会给这部分用户显示刺眼的白色背景，立即损害第一印象和感知质量。

**实现方式**: 在 `@media (prefers-color-scheme: dark)` 块中重新声明 CSS 自定义属性。品牌强调色（狗狗琥珀色、猫咪紫罗兰色、状态颜色）有意保持不变 — 它们在深色背景上可读性更好、更清晰。

```css
@media (prefers-color-scheme: dark) {
  /* 表面和背景反转 */
  --white:        #0F172A;   /* 页面背景 → 近黑色 navy */
  --gray-50:      #1E293B;   /* 交替区块背景 */
  --gray-100:     #334155;   /* 输入框背景、禁用状态 */
  --gray-300:     #475569;   /* 边框、分隔线（调亮以增强可见性） */

  /* 文本反转 */
  --gray-500:     #94A3B8;   /* 次要文本、占位符 */
  --gray-700:     #CBD5E1;   /* 正文文本 */
  --gray-900:     #F1F5F9;   /* 标题文本 → 近白色 */

  /* Brand navy 反转为浅色（在深色背景上用作文本） */
  --brand-navy:   #E2E8F0;

  /* Teal 保持不变 — 在深色背景上依然鲜艳 */
  /* --brand-teal: #0D9488  (未更改) */
  /* --brand-teal-light → 为深色背景卡片略微调暗 */
  --brand-teal-light: #0F766E;

  /* 狗狗板块 — amber 保持不变，表面调暗 */
  --dog-primary-light: #451A03;  /* 深色模式下的卡片背景 */
  --dog-surface:       #1C0E00;

  /* 猫咪板块 — violet 保持不变，表面调暗 */
  --cat-primary-light: #2E1065;
  --cat-surface:       #13072B;

  /* 状态背景 — 为深色模式可读性调暗 */
  --status-safe-bg:    #064E3B;
  --status-caution-bg: #451A03;
  --status-toxic-bg:   #450A0A;
  --status-info-bg:    #1E3A5F;
}
```

**测试要求**: 所有工具页面在浅色和深色模式下都必须通过 WCAG AA 对比度要求（正文文本 4.5:1，大文本 3:1）。在 QA 阶段使用 [Colour Contrast Analyser](https://www.tpgi.com/color-contrast-checker/)。

## 3. 排版

### 3.1 字体栈

```css
/* 显示和标题 */
font-family: 'Plus Jakarta Sans', 'Inter', system-ui, sans-serif;

/* 正文和 UI */
font-family: 'Inter', system-ui, -apple-system, sans-serif;

/* 数字和结果（等宽感觉） */
font-family: 'DM Mono', 'JetBrains Mono', monospace;
```

**加载策略**: 仅包含 Latin + Latin-Extended 子集。预加载关键字重（400、600、700）。

## 8. 动效与动画

**原则**: 仅使用有目的的动效。绝不只为装饰而设置动画。

| 交互 | 动画 | 持续时间 |
|---|---|---|
| 页面过渡 | 淡入 `opacity: 0→1` | 150ms ease-out |
| 卡片悬停 | `translateY(-2px)` + 阴影 | 120ms ease |
| 结果展示 | 上滑 + 淡入 | 300ms ease-out |
| 步骤过渡 | 左右滑动 | 250ms ease-in-out |
| Tooltip | 淡入 + 从 0.95 缩放 | 100ms ease |
| 加载状态 | 骨架屏闪光 | 无限 |
| 数字计数器 | 从 0 开始计数 | 800ms ease-out |

**尊重 `prefers-reduced-motion`**: 所有动画都必须有 `@media (prefers-reduced-motion)` 覆盖。

## 9. 无障碍标准（WCAG 2.1 AA）

- **颜色对比度**: 正文文本至少 4.5:1，大文本 3:1
- **焦点指示器**: 所有交互元素都有可见的 3px teal 轮廓
- **ARIA 标签**: 所有表单输入、按钮、状态徽章
- **键盘导航**: 完整的 tab 顺序，无键盘陷阱
- **屏幕阅读器**: 通过 `aria-live="polite"` 进行结果播报
- **Alt 文本**: 所有装饰性图片使用 `alt=""`，信息性图片使用描述性 alt

**关键配对的对比度检查**:
- `--gray-700` 在 `--white` 上: 7.2:1 ✅
- `--brand-navy` 在 `--white` 上: 12.1:1 ✅
- 白色在 `--dog-primary` 上: 3.4:1（仅大文本，辅以图标）
- 白色在 `--cat-primary` 上: 5.8:1 ✅
- 白色在 `--brand-teal` 上: 4.7:1 ✅

## 12. GDPR 与隐私设计

- **Cookie 横幅**: 极简，仅在首次访问时显示。选项: 全部接受 / 拒绝非必要
- **不收集数据**，除了选择加入的电子邮件（疫苗提醒）
- **仅使用 localStorage**: 在隐私政策中明确披露
- **分析**: 隐私优先分析（Plausible.io 或 Fathom — 无 cookies，无 PII）
- **字体托管**: 自托管（避免在欧盟使用 Google Fonts 的 GDPR 风险）
